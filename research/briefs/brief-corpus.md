# Lane: public schema corpus sweep

Read /tmp/claude/graph_weaver/brief-common.md for toolchain, gate, trailers. Baseline: main **4fd16d2** (you are in a worktree off it). CHANGELOG lane marker `<!-- lane: corpus -->` as a new block under `###  Unreleased`. Every gate command its own Bash call. Cached dumps live under your scratchpad, never in the repo.

You are the engineer who does not trust three schemas. Codegen and the round-trip harness have only ever been run against GitHub, Countries and PokeAPI (cached under `$TMPDIR`; see `spec/integration/**` and `bin/round-trip` for how those are fetched). Every codegen bug found this release came from a shape one of those three happened to have. Your job is to widen the net cheaply: gather a dozen or more real public schemas of different pedigrees, run generation and the property harness over each, and turn every failure into either a fix with a regression spec or a precise report.

Corpus, gather what you can (introspect where the endpoint allows it, fetch SDL from the project's repo where it doesn't; skip anything that needs credentials): Rick and Morty (rickandmortyapi.com/graphql), AniList (graphql.anilist.co), SWAPI (swapi-graphql.netlify.app/.netlify/functions/index), SpaceX (spacex-production.up.railway.app), GitLab (gitlab.com/api/graphql, introspection is open and it is huge), Linear's SDL (github linear/linear `packages/sdk/src/schema.graphql`), Shopify Admin or Storefront SDL (published in shopify's github or npm), a Hasura-shaped one beyond PokeAPI, a WordPress WPGraphQL demo, and anything from APIs-guru/graphql-apis or graphql-kit/graphql-apis that introspects. Record for each: source url, fetch method, size (types, input types), and the tool that read it. If a fetch fails, say so and move on; don't spend more than a few minutes per source.

Per schema, in order: `SchemaLoader.load` reads it; `bin/round-trip <dump> -c 100 -s 1`, then `-s 101` and `-s 201` (chunk by seed, never a large `-c`: superlinear, and `-c 1000` on PokeAPI died at 6 GB); `--hostile -c 100` once; and the `rake graph_weaver:unused`/`queries:check` path is not in scope. Where a schema has a public example query set (GitLab, Shopify, Linear ship docs with queries), run `bin/round-trip <dump> -q <dir>` on a handful.

Triage each failure: harness bug, codegen bug, loader bug, or a schema the spec says is legal but graphql-ruby refuses (report those, don't work around them). For codegen and coerce bugs: minimal inline SDL repro, spec that fails before the fix, fix, gate. For anything in `schema_loader.rb`: REPORT with the repro, another lane owns it right now. Reserved-name collisions across the corpus: list every coordinate the prop rule renames, so we know the rule's real-world hit rate.

Ownership: `lib/graph_weaver/codegen.rb`, `lib/graph_weaver/codegen/**`, `lib/graph_weaver/coerce.rb`, `lib/graph_weaver/inflect.rb`, `lib/graph_weaver/hints.rb`, `spec/support/round_trip.rb`, `bin/round-trip`, `spec/round_trip_spec.rb`, `spec/codegen_spec.rb`, new specs, `spec/generated/**` via `bin/generate`, `docs/generated_modules.md`, `CHANGELOG.md` (your block), `spec/support/public_surface.txt` via `bin/public-surface --update`.
