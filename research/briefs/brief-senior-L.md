You own the composition for a company with six teams: the supergraph is yours, the subgraphs are theirs, and graph_weaver is what their Rails apps use to call it. Your question is whether graph_weaver fits the workflows a supergraph owner actually runs.

- **Contracts and variants.** Compose a contract variant with `@tag` (rover's `--contract`, or hand-filter with the tags): a `public` variant hiding `@tag(name: "internal")` fields. An app generated against the internal supergraph calling the public endpoint, and vice versa: what `verify`, `schema:diff`, and runtime say. Multiple supergraph files in one app (staging vs prod) — is there a spelling, or only one dump per graph.
- **rover in the loop.** `rover subgraph check`/`publish`-shaped workflow: a subgraph change that composition accepts but breaks a client query (field removed, type narrowed, argument made required, enum value removed, `@inaccessible` added). For each: which graph_weaver check catches it and when — `queries:check`, `verify`, `federation:diff`, generation, runtime — and whether a CI gate the client team can run (docs/getting_started §5's CI scripts) would have gone red before deploy. Write the table.
- **Schema evolution the spec allows.** A field deprecated with `@deprecated(reason:)` then removed; a new required argument with a default; a union gaining a member; an interface gaining a field; an enum value renamed; a scalar changing its serialization (String → custom): generated code and `srb tc` before and after each, and whether any of these is a silent runtime change for a client that didn't regenerate.
- **The federation tasks as a supergraph owner would use them.** `federation:diff` across all six subgraphs from one repo (the "unplaced" warning, the new "shape" kind, the retired-subgraph case); is there a way to run them against subgraph SDL files rather than loaded Ruby classes (other teams' subgraphs aren't Ruby); what a non-Ruby subgraph looks like to every task.
- **Docs for the six teams.** Read docs/federation.md as the person who has to hand it to five other teams: what's missing for a client team that never composes anything, and what's there that only the owner needs.
