## Where to dig, in order

1. **Reserved-name props (`name_`)**: an input type with `class` and a nested object also named `class`; a `name_` prop under `:wire` (the endpoint sees the wire name?); `InputError#path` and `#coordinate` for a renamed field (path is the wire name per the lane — is that what a form wants, or the prop?); `graphql_fake("Thing.class" => …)` pins by wire name — does it reach the `class_` prop?; the `# wire:` comment under `# typed: strict`; `to_h`/`deconstruct_keys` on `class_`; `did_you_mean` from `coerce(class: …)`; an alias `class` in an `extend_type(alias:)` still refused; a field named `_` or `__` or `class__`.
2. **Module-owned dispatch and `:graph`**: `MyQuery.client =` and per-call `client:` still win through `dispatch`; a module from `GraphWeaver.parse` with and without `graph:`; the fiber-local's extent across `Retry` (retries inside one dispatch — does `:retries` still count?), across `:wire`'s Rack endpoint (the served resolver runs a *different* module — whose graph does its event carry?), across threads spawned inside a resolver, across a raise mid-dispatch (is the local cleared?); `LogSubscriber`'s line for every status; the payload key set spec still asserting the whole set.
3. **`rake graph_weaver:unused`**: a prop named `name`/`id`/`type` (the false-negative the footer warns about — measure how often on the dogfood app); a read only in a `.erb` with `<%= result.person.name %>`; a `case result in {person: {name:}}` pattern; a `to_h` on a *variable* holding the struct; two graphs with the same query file name; `PATHS` pointing at a nonexistent dir; a generated dir that isn't named `generated`; a Rails app with `app/graphql` server types under a different directory than the lint expects (false reads from `field :x`); STRICT=1 exit code and stderr/stdout split; the task on a repo with zero queries.
4. **Observability**: `GraphWeaver.instrumenter` set by the app AFTER the railtie ran (does the railtie's auto-wire override it, or vice versa?); a subscriber that raises (does it break the request?); `duration_ms` under `Retry` (per attempt or total?); `:code` when the first error has none but a later one does; the `LogSubscriber` when `GraphWeaver.logger` is nil vs `Rails.logger`; the OTel/Datadog samples as pasted against the current gems; `:http_status` on a 200 with `errors`; in-process `:schema` for an anonymous schema class.
